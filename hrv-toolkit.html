換算 Convert

  • 把一串資料在 Text、Hex、Decimal、Octal、Binary 之間互轉，ipmitool 除錯時最常用。

    • 上方兩個下拉選單選來源與目標，中間的 ⇄ 可以互換。
    • 兩種模式由來源與目標自動決定：只要有一端是 Text，就是位元組模式，逐個位元組對應（Hex 要偶數個字元、Binary 要 8 的倍數、十進位與八進位每項要在 0 到 255）；兩端都是數值，就是數值模式，每個用空白分隔的項目各自換算，不限寬度。
    • 編碼固定是 ASCII。Text 輸出裡的控制字元會顯示成 \xNN，不會變成看不見的字。
    • 輸出可以選格式：0x49 0x50、49 50、4950、\x49\x50 或 C array，Hex 另外可選大寫或小寫。
    • 貼上很寬鬆：0x、\x 這類前綴與逗號、空白、換行都會自動清掉；輸入有錯會說明怎麼修。
    • 換算完安靜三分鐘，會自動記進「最近五筆」，點一筆就帶回輸入欄。

  • 扭力單位換算，鎖 CPU 與散熱片時對照規格用。

    • 九個單位分三組：公制（mN·m、cN·m、N·m）、英制（ozf·in、lbf·in、lbf·ft）、公斤力（gf·cm、kgf·cm、kgf·m）。
    • 任何一欄都可以當輸入端，輸入哪一欄，其餘八欄就即時更新；當前輸入端的框是亮的，其餘是內凹的讀數。
    • 換算以 N·m 為基準，係數都用精確定義值（1 lbf = 4.4482216152605 N、1 in = 25.4 mm、1 kgf = 9.80665 N），顯示 6 位有效數字。
    • 空欄位裡的灰字是 1 N·m 的等值，用來對照量級，不是換算結果。
    • 負值照算（代表鬆脫方向）；輸入有錯時會清掉其他八欄，不留舊數字讓你抄錯。
    • 每一欄都有複製鈕；換算完安靜三分鐘，會自動記進「最近五筆」。

  • 資料大小與傳輸速率的互換，分成兩個各自獨立的區塊。

    • 資料大小：Bytes、KB、MB、GB、TB（十進位，1000）與 KiB、MiB、GiB、TiB（二進位，1024）並列在不同欄，沒有切換鈕，不會看錯是哪一種。
    • 傳輸速率：bit/s 系列（b/s 到 Tb/s）、Byte/s 十進位（B/s 到 TB/s）與 Byte/s 二進位（KiB/s 到 TiB/s）。小寫 b 是 bit，大寫 B 是 Byte，1 Byte = 8 bit。
    • 任何一欄都可以當輸入端，同一區其餘欄位即時更新；例如填 GB/s，就同時看到 Gb/s 與 GiB/s。
    • Bytes 與 bit 是整數時顯示完整數字（1 TiB = 1099511627776 Bytes），其他顯示 6 位有效數字；負值照算，可以用在兩次量測的差。
    • 每一欄都有複製鈕；「最近五筆」只記最後動過的那一區。

記錄 Record

  • 記地端機器的網路資訊：IP、MAC、電腦名稱與地點。

    • 每一組最多四個 IP，每個 IP 配一個自己的 MAC，用框格框在一起；IP 右邊的下拉選單標示種類：Host、BMC、FPGA、Controller、RM、RSCM、MGMT Switch、TOR Switch。
    • IP 1 必填，其餘可以留空。另外有組名、電腦名稱、地點三個欄位。
    • 只檢查 IPv4（四段，各 0 到 255）與 MAC（12 個 hex 字元），格式有誤會提示怎麼修，但不擋存入；MAC 有填、同一組的 IP 卻空白，也會提醒。
    • 每個欄位都有複製鈕，複製的是你輸入的原文。
    • 五個存檔格：存入才會寫進去，並自動記下存檔時間（含年份）；表單內容重新載入後還在。

  • 記錄各專案階段的 Firmware 版本，整理成可以傳給 RD 的文字。

    • 先填專案名稱與階段（POC、EV、DV、PV、MP、DoE）。
    • 九個 Firmware 欄位：BIOS、BMC、SCM CPLD、HPM CPLD、Manticore、TPM、SoC OS、SoC Firmware、FPGA Cerberus。
    • 自動偵測：把從 RM 撈出的原始輸出貼進偵測區，認得的欄位（BIOS、BMC、SCM CPLD、HPM CPLD）會自動填入，並說明填了哪些、沒偵測到哪些；BMC、SCM CPLD、HPM CPLD 抓到兩筆相同的值只留一筆。貼上的原文不會被存起來。
    • 按「產出」會把有填的欄位整理成「名稱: 值」，一行一個，沒填的不出現，可以直接複製；欄位一有變動，已產出的文字就會清除。
    • 備註可以寫測試項目與問題釐清；每個欄位都有複製鈕。
    • 五個存檔格，專案欄就是存檔名稱，存檔時間含年份。

  • 把兩份文字左右並排，逐行比對，差異即時標出來。

    • 左右各貼一份文字，結果一列對一列，左右一起捲動；長的行會換行，不會讓兩邊錯位。
    • 差異分三種：只在左邊（紅）、只在右邊（綠）、修改（黃）。修改的行會再把不同的字加粗；版本字串、IP、MAC 會整個當成一個字標出來。
    • 選項：忽略大小寫、忽略空白差異（只影響比對，畫面仍顯示原文）；「只看差異」把相同的行摺起來，差異前後各留 3 行。
    • 上一個、下一個差異：在差異區塊之間跳，並顯示目前是第幾處。
    • 搜尋：左右兩邊同時搜尋，不分大小寫，顯示左右各有幾筆，可以逐筆往下或往上跳（Enter 與 Shift 加 Enter）。
    • 「複製差異」複製成 unified diff 格式，貼進 Jira 或 Slack 最清楚；也可以左右互換。每邊最多 50000 行；貼上的內容不存檔。

  • 三個可以各自收合的區塊：指令筆記、暫存區、自由筆記。

    • 指令筆記：把常用指令存進指令庫（最多 20 筆）；指令裡寫 {變數} 當佔位符，就會長出填入欄，填完即時組出完整指令，全部填好才能複製。IP Address Recorder 存過的組別，可以從下拉選單直接帶入 IP、MAC 或電腦名稱。填入的值不會存檔，指令庫沒有加密，不要存密碼。
    • 暫存區：貼上 SEL 或任何 log，用關鍵字（逗號分隔、不分大小寫）只留或刪掉符合的行，也可以去除重複行，再複製結果。原文不存檔；結果區最多顯示 5000 行，但複製會複製全部。
    • 自由筆記：一塊空白區，輸入時自動存，另有五個存檔格，可以留住不同版本的筆記。
    • 刪除與清空要按兩次才會執行，避免手滑弄丟累積的內容。

排程 Schedule

  • 算 non-op 測試的完成日與開箱日。

    • 三種測試：Cold And Hot Storage（低溫、高溫各一段，各接一次開箱）、High Temp High Humidity（填總時數，可插中途開箱）、Thermal Cycling Test（填總圈數，可插中途開箱；每圈時間可由溫度、升降溫速率與停駐時間算出，也可以直接輸入）。
    • 測試本身 24 小時連續進行，週末照跑；只有開箱受工作日限制。段落結束在中午 12:00 前，排當天開箱；12:00 後，排隔天；遇到週六、週日或排除日，就往後推到下一個工作日。
    • 開箱時數（預設 8 小時）與開箱時間（預設 10:00）可以改；最後一段跑完固定再開箱一次。
    • 結果是預計完成時間，加上一條時間軸：測試、等待工作日、開箱檢測每一段的起迄與長度。
    • 查詢（High Temp High Humidity 與 Thermal Cycling Test）：給第幾圈或第幾小時，查何時完成；給一個時刻，查已完成多少，並標明狀態（測試中、開箱中、等待開箱中、尚未開始、已完成）。
    • 排除日期欄下方有月曆，點平日就設成假日。輸入會記在這台裝置，另有五個存檔格。

  • 輸入起迄日與里程碑，算出時間進度，回報與追進度用。

    • 設定開始日、結束日與基準日（預設今天，可以改成任何一天）；里程碑可以新增多筆（名稱加日期），會依日期自動排序。
    • 進度區顯示完成度（日曆天）與工作天完成度、已過與距離結束的天數，以及一條帶里程碑刻度的進度條；里程碑表列出每個里程碑距開始、距基準日的天數與完成度。
    • 天數用日期差計算：開始日是 0%、結束日是 100%（9/4 到 9/30 是 26 天）；工作天含起日、不含迄日，並扣掉週末與排除日期。
    • 反推：輸入完成度百分比，換回日期，同時給日曆天與工作天兩個日期。
    • 「複製摘要」給一行純文字，可以直接貼進週報或 Jira。
    • 排除日期欄下方有月曆，點平日就設成假日。另有五個存檔格。

                存入才會寫進格子，不會自動存；存入時自動記下時間。存入已有資料的格子會直接覆蓋。專案欄就是每一格的名稱。五個格子只存在這台裝置。

                說明 Notes

                • 自動偵測：把從 RM 撈出的原始輸出整段貼進偵測區，會逐行找「欄位名稱: 值」，認得的就填進下面的 Firmware 欄位；沒認出來的欄位原樣不動，手動填。
                • 目前認得的對應：BIOS ← BiosVersion；BMC ← BMCVersion（BMC2Version 不同時用 " / " 接在後面）；SCM CPLD ← DCSCMCpldVersion；HPM CPLD ← CpldVersion。其他欄位目前沒有對應，先手動填。
                • 貼上的值若和欄位裡原有的不同，會覆蓋，並在訊息列列出原值。貼上區之後再被編輯時，已經填過的值不會把你手動改過的欄位又蓋回去。
                • 貼上區的原文不會被存起來（裡面常有序號、UUID、MAC），只有填進欄位的版本字串會跟著存檔。要清掉原文按「清空貼上區」。
                • BMC、SCM CPLD、HPM CPLD 抓到兩筆相同的值（例如 03.06.00,03.06.00）時只留一筆；兩筆不一樣就原樣保留並提示。
                • 產出：按「產出」會把有填值的 Firmware 欄位整理成「名稱: 值」，一行一個，沒填的不出現，可直接複製傳給 RD。產出內容不含專案、階段與備註。欄位一有變動，已產出的文字會自動清除，避免複製到過時的內容。
                • 每個欄位右邊的「複製」只複製該欄的文字，不含標籤。
                • 所有內容只存在這台裝置的瀏覽器裡，不上傳。清除瀏覽器資料就會一起消失，換裝置也不會同步。

                  存檔 Saves

                    上面那塊筆記會自動存；存入才會寫進格子，不會自動存，存入時自動記下時間。存入已有資料的格子會直接覆蓋。五個格子只存在這台裝置。

                    說明 Notes

                    • 三個區塊各自可以展開或收合，標題下面那一行說明收合時也看得到；展開狀態會記在這台裝置上。
                    • 指令筆記：指令裡的 {NAME}（英文字母、數字、底線，不能以數字開頭）是佔位符，會自動長出填入欄，填完即時組出完整指令，全部填好才能複製。${HOME} 這種 shell 變數與 {print $1} 這種含空白的大括號不會被當成佔位符；真的要寫字面的 {NAME} 就加反斜線 \{NAME}。
                    • 帶入 IP：在 IP Address Recorder 存過的組別，每個填入欄旁邊會多一個下拉選單，可以直接帶入該組的 IP、MAC 或電腦名稱。
                    • 填入的值不會存檔，關掉或重新載入就清空；同名的變數在不同指令之間共用，填一次就好。指令庫沒有加密，不要把密碼寫進指令，密碼請用 {PASSWORD} 這類佔位符現場填。
                    • 指令庫最多 20 筆；名稱相同按「存入指令庫」會更新那一筆。刪除與清空要按兩次才會執行。
                    • 暫存區的原文不會存檔（log 常含序號、位址，也可能很大），重新載入就清空。關鍵字用逗號分隔，符合任何一個就算，不分大小寫；去重保留第一次出現的那一行。
                    • 自由筆記最多 20000 字，輸入時自動存「目前這份」。另有五個存檔格：按「存入」才會把目前這份寫進格子（名稱留空就用存檔時間），「讀取」會把那一格換回上面的筆記，所以讀取前如果目前這份還沒存，會被換掉。清除格子不影響上面的筆記。
                    • 指令庫與自由筆記只存在這台裝置的瀏覽器裡，不上傳。清除瀏覽器資料就會一起消失，換裝置也不會同步。
                    Text Comparer v1.0.0

                    輸入 Input

                    比對結果 Result

                    左右各貼一份文字，差異會即時顯示在這裡。

                    − 只在左邊（或修改前）　+ 只在右邊（或修改後）　紅底＝只在左邊，綠底＝只在右邊，黃底＝修改，修改的行裡不同的字會加粗。

                    說明 Notes

                    • 左右各貼一份文字，差異即時顯示。結果是一列對一列，左右一起捲動；長的行會換行，不會讓兩邊錯位。
                    • 標示：行首的 − 與 + 加底色（紅、綠、黃），不單靠顏色。修改的行會再把不同的字加粗；版本字串（例如 26.8.14-2）、IP、MAC、路徑會當成一個字整個標出來。
                    • 忽略大小寫與忽略空白差異（連續空白視為一個、去掉前後空白）只影響比對，畫面上顯示的仍是原文。
                    • 只看差異會把相同的行摺起來，差異前後各留 3 行。「上一個差異」「下一個差異」會在差異區塊之間跳，並顯示目前是第幾處。
                    • 搜尋左右兩邊同時進行，不分大小寫，關鍵字當純文字；Enter 跳到下一筆，Shift 加 Enter 跳到上一筆。只搜尋畫出來的列。
                    • 複製差異複製成 unified diff 格式（− 與 + 開頭、前後各 3 行），貼進 Jira 或 Slack 的程式碼區塊最清楚。
                    • 搬動過位置的行算「一刪一增」。每邊最多 50000 行；兩邊差異超過 3000 處無法逐行比對，會說明並建議先各自排序或分段貼上；結果最多畫 4000 列。
                    • 手機上左右改成上下成對排列。貼上的內容與選項都不存檔（比對的文字常含序號與位址），重新載入就清空。

                    維護 Maintenance

                    • 載入時會自動跑一次九支工具的邏輯自我檢查。全部通過時不顯示任何東西；只要有一項不符預期，內容區就會跳出紅框並列出是哪一支工具的哪一項。看到紅框就不要採用它算出來的數字。
                    • 工具內建的常數只有公開標準（單位換算係數、ASCII 表）。所有測試條件、溫度、時數、規格值都由使用者當場輸入。
                    • 更新這個檔案後要一起改 sw.js 裡的 CACHE 版本號，否則已安裝的裝置會繼續用舊的快取版本。
                    • String / Torque / Data Size 在換算完靜置三分鐘後會自動記下該組輸入，最多五筆；Non-Op / Milestone / IP Address Recorder / Firmware Recorder 有五個需要手動存入的具名存檔格。兩者都只存在這台裝置的瀏覽器裡。
                    • 左側底部的太陽／月亮鈕切換淺色與深色。沒選過就跟著系統，選過的記在這台裝置的瀏覽器裡（hrv.theme）。
                    • Personal Notes 的指令庫（最多 20 筆）與自由筆記存在這台裝置的瀏覽器裡，沒有加密；暫存區的原文與指令的變數值不存檔。
